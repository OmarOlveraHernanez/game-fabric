# Arte fuente

Archivos editables (PSD, Aseprite, Krita) y **prompts de IA** usados para generar sprites.
Los PNG exportados para el juego van en `games/<Juego>/Assets/_Game/Art/`.

Convenciones:
- Guardar cada prompt en `prompts/` con la herramienta usada y su licencia de uso comercial.
- PPU (pixels per unit) y paleta fijados por juego en su `CLAUDE.md`.
