# Game Factory

Fábrica de videojuegos 2D para Android con Unity 6.3 LTS, C# y Claude Code.

| Carpeta | Contenido |
|---|---|
| `packages/com.gamefactory.core` | Núcleo compartido (Game Factory Core) |
| `games/ChihuahuaJump` | Primer juego |
| `tools/` | Scripts de entorno, pruebas, build e instalación |
| `docs/` | Arquitectura, setup, checklist de lanzamiento, decisiones |
| `art-source/` | Arte fuente y prompts de IA |

Empieza por `docs/SETUP.md` (entorno) y `docs/ARCHITECTURE.md` (plan).

**Regla de oro:** nada se sube (push) ni se publica sin validación manual. Ver `docs/RELEASE_CHECKLIST.md`.
